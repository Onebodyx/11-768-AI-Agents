## Как устроены конспекты

Каждый файл содержит:

- краткое изложение основных идей;
- подробное объяснение материала;
- разбор упомянутых примеров и исследований;
- практические выводы для разработчика агентов;
- ограничения и открытые вопросы;
- словарь ключевых терминов;
- вопросы для самопроверки;
- ссылки на основные фрагменты видеозаписи.

Конспекты составлены по официальным слайдам и автоматическим английским субтитрам YouTube. Это смысловая переработка, а не дословный перевод. В автоматической расшифровке возможны ошибки, особенно в фамилиях, названиях работ и программных терминах; в спорных случаях приоритет отдан официальным слайдам.
